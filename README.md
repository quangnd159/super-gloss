# Super Gloss

A dictionary for macOS 15+. Type a word and every dictionary you own answers on a single page. Each dictionary's name sits in the margin beside its entry.

Super Gloss doesn't include any dictionaries. It reads the dictionary files you already have.

The engine is written in Rust and the app in Swift. Supported formats:

| Format | Files |
| --- | --- |
| MDict | `.mdx` + `.mdd` (v1/v2, encrypted key index, multi-volume `.mdd`) |
| StarDict | `.ifo` + `.idx[.gz]` + `.dict[.dz]` (+ `.syn`) |
| ABBYY Lingvo DSL | `.dsl[.dz]` + `_abrv.dsl`, `.ann`, `.files.zip` / `.files/` |
| Babylon | `.bgl` |
| dictd | `.index` + `.dict[.dz]` |
| XDXF | `.xdxf` |

## Install

Download the latest `SuperGloss-<version>.dmg` from [Releases](https://github.com/quangnd159/super-gloss/releases), open it, and drag Super Gloss to Applications. It's a universal app (Apple Silicon and Intel), signed and notarized.

## Build

Needs Xcode 26+ (for the Icon Composer app icon), Rust (`rustup`) with both Mac targets, and [xcodegen](https://github.com/yonaskolb/XcodeGen):

```sh
rustup target add aarch64-apple-darwin x86_64-apple-darwin
brew install xcodegen
./build.sh            # universal Release → app/build/DerivedData/Build/Products/Release/Super Gloss.app
./build.sh Debug
```

The Xcode project comes from `app/project.yml`. Its pre-build step compiles the Rust core for each architecture, so a regular Xcode build works too. Local builds are signed ad hoc. `scripts/release.sh` signs with a Developer ID, then packages, notarizes and staples a DMG in `dist/`.

The app icon is an Icon Composer document, `app/SuperGloss/AppIcon.icon`, generated by `app/tools/make-icons.py`.

## Using it

On first launch, drop a folder of dictionaries onto the window (or choose **File → Add Dictionaries…**). Each dictionary is indexed once and reopened from the cache in milliseconds after that.

| | |
| --- | --- |
| type | live results as you type; the gray completion shows the best match |
| `Tab` / `Return` | accept the completion / look the word up |
| `↑` `↓` | move along the word strip |
| `⌥⌘↓` `⌥⌘↑` | jump to the next / previous dictionary |
| `⌘[` `⌘]` | back / forward |
| `⌘P` | pronounce |
| `⌘R` | a random word |
| `⌘=` `⌘-` `⌘0` | text size |
| `⌘/` | every keyboard shortcut |
| double-click a word in an entry | look it up |
| `⌥Space` (anywhere) | show or hide Super Gloss (change it in Settings) |

You can also look words up from other apps. Select text and choose **Services → Look Up in Super Gloss**, or open a URL like `supergloss://lookup?q=word`.

To reorder or hide dictionaries, use **Settings → Sources**. Click a dictionary's name in the margin to collapse its entry.

## Layout

```
core/   Rust engine: format readers, FST index, search, HTML rendering, C API (include/supergloss.h)
cli/    `sgloss` — command line tool for indexing, lookup, benchmarks and verification
app/    SwiftUI/AppKit app; Web/ holds the reading surface (HTML/CSS/JS)
```

Indexes are cached in `~/Library/Caches/app.supergloss.SuperGloss/Indexes`.

To check a dictionary collection from the command line:

```sh
cargo run --release -p sgloss -- verify /path/to/dictionaries   # render samples from every dictionary
cargo run --release -p sgloss -- bench  /path/to/dictionaries
cargo run --release -p sgloss -- lookup serendipity /path/to/dictionaries
```
